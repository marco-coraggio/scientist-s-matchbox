## What it is
-------------

Scientist's Matchbox is a free collection of carefully crafted templates and guides, specifically designed to enhance scientific production. Just like a physical matchbox, it's a container full of handy little tools you can use when you need to spark your research ideas.

The collection is primarily intended for academics working in scientific fields, but anyone needing neat templates for technical work could use them.

The resources in Scientist's Matchbox are designed to encourage the creation of documents that are:

1. Structured
2. Concise
3. Precise
4. Visually pleasing
5. Well-referenced


## Content 
----------

Templates:

------o  Report in LaTeX
------o  Report in Microsoft Word
------o  Presentation in Microsoft PowerPoint (4:3 and 16:9)
------o  Presentation in LaTeX beamer (4:3)
------o  Thesis in LaTeX
------o  Poster in Microsoft PowerPoint (A2 vertical)
------o  Gantt chart in Microsoft Excel
------o  Structured text file

Guides:

------o  Beginner tips to write scientific documents
------o  Miniguide to LaTeX equation environments on multiple lines
